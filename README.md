# Mini Compliance Program - TechNova Solutions



## Project Overview



This repository contains a simulated Governance, Risk, and Compliance (GRC) assessment for **TechNova Solutions**, a fictional technology organization.



The project demonstrates how an organization can establish a structured information security compliance program by identifying assets, assessing cybersecurity risks, mapping security controls, evaluating control maturity, and maintaining an evidence register.



The assessment references:



- ISO/IEC 27001:2022

- NIST SP 800-53 Revision 5



## Project Objectives



The objectives of this project are to:



- Identify and classify organizational information assets.

- Identify and assess cybersecurity risks.

- Map security controls to recognized frameworks.

- Evaluate information security control maturity.

- Identify compliance gaps and improvement opportunities.

- Define remediation actions and responsibilities.

- Establish an evidence register for audit readiness.



## Project Scope



The simulated assessment covers the following business areas:



- Information Technology

- Human Resources

- Finance

- Software Development

- Security and Governance, Risk and Compliance (GRC)



Technology assets include cloud infrastructure, AWS S3 storage, employee devices, databases, business applications, source code repositories, and network infrastructure.

## Risk Assessment Approach



Risks are assessed using a 5 Ã— 5 risk scoring methodology.



**Risk Score = Likelihood Ã— Impact**



| Score | Risk Rating |

|---|---|

| 1-4 | Low |

| 5-9 | Medium |

| 10-16 | High |

| 17-25 | Critical |



The risk register includes risk descriptions, ratings, responsible owners, and proposed treatment actions.



## Control Maturity Assessment



A six-level maturity scale is used:



| Score | Maturity Level |

|---|---|

| 0 | Not Performed |

| 1 | Initial |

| 2 | Developing |

| 3 | Defined |

| 4 | Managed |

| 5 | Optimized |



The target maturity level for the assessment is Level 3 - Defined.



Current maturity scores are preliminary assessment assumptions. Scores based on proposed documentation or design are explicitly identified as provisional and are not verified implementation results.

## Key Outcomes



This project establishes a documented starting point for a fictional organization's compliance program.



Key outputs include:



- 10 identified organizational assets.

- 10 documented cybersecurity risks.

- 20 mapped security controls.

- 20 preliminary control maturity assessments.

- 12 defined evidence requirements.

- Proposed remediation and continuous improvement activities.



## Limitations and Assumptions



- TechNova Solutions is a fictional organization created for this portfolio exercise.

- The assessment is simulated and based on proposed organizational assumptions.

- No independent audit or certification assessment has been performed.

- Evidence requirements are documented, but actual implementation evidence has not been independently collected or verified.

- No live AWS environment or production infrastructure has been assessed.

- The project does not demonstrate ISO/IEC 27001 certification or formal compliance.
