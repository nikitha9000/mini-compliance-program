## 4. Key Findings



1. Formal information security policies require development and approval.

2. Access control and identity management require documented procedures.

3. Incident response arrangements need to be established.

4. Vulnerability assessment and security monitoring need improvement.

5. Business continuity and disaster recovery procedures require development.

6. Security evidence needs to be collected and reviewed.
