## 1. Purpose



The purpose of this Evidence Register is to identify, document and track evidence required to support information security control assessments at TechNova Solutions.



Evidence helps demonstrate whether security controls are implemented, operating effectively and aligned with applicable security requirements.

## 3. Evidence Status Definitions



| Status | Description |

|---|---|

| Available | Evidence has been collected and recorded |

| Pending | Evidence has not yet been collected |

| Under Review | Evidence is being examined |

| Accepted | Evidence has been reviewed and accepted |

| Rejected | Evidence is insufficient or does not meet requirements |



## 4. Evidence Collection Requirements



Each evidence item should:



1. Have a unique evidence identifier.

2. Be linked to a relevant security control.

3. Identify the responsible evidence owner.

4. Include a collection date when collected.

5. Be relevant to the control being assessed.

6. Be stored securely with appropriate access restrictions.

7. Be reviewed for accuracy, completeness and reliability.

8. Be updated when the control or system changes.



## 5. Evidence Storage and Protection



Evidence should be maintained in an approved, access-controlled repository.



Sensitive evidence such as system configurations, access records and security logs must be protected against unauthorized access, modification or disclosure.



Evidence retention periods should follow the organization's approved retention requirements.



## 6. Evidence Review Process



The GRC Analyst coordinates evidence collection and review.



The process includes:



- Requesting evidence from assigned control owners.

- Recording received evidence in the register.

- Checking relevance and completeness.

- Linking evidence to the relevant control.

- Identifying missing or insufficient evidence.

- Updating evidence status.

- Recording review observations and follow-up actions.

Listing an evidence item does not mean the related security control has been implemented or proven effective.
